# 筆記動作ラボ

スマートフォン等で撮影した筆記動画をブラウザ内で解析し、MediaPipe Hand Landmarkerのランドマーク、動作特徴量、参加者・試行単位の集約データをCSV出力する研究用Webアプリです。筆記速度・正確性を予測するモデルは含みません。

## 実行

`outputs`フォルダーをローカルHTTPサーバーで配信します。`outputs`へ移動して `python -m http.server 8000` を実行し、`http://localhost:8000/writing-motion-lab/` を開きます。`file://`での直接起動は使わないでください。CDNからMediaPipe Tasks Vision 0.10.22-rc.20250304のES module（`vision_bundle.mjs`）、同じバージョンのWASM、公式Hand Landmarkerモデルを取得するためインターネット接続が必要です。MediaPipe本体は動画選択後の解析時に遅延読込するため、CDN障害が動画選択やプレビューを妨げません。

匿名の参加者IDと試行IDを入力し、任意で撮影条件を記録して解析します。解析開始時の入力値を固定してCSVに使うため、解析後に画面を編集しても結果のメタデータは変わりません。高さ・距離は空欄にできます。不正または0以下の数値は空欄として保存し、解析完了メッセージで知らせます。

動画変更時は前の解析結果を消去します。解析中は動画・設定入力を無効にし、解析エラー時は部分データを破棄してCSVを無効化します。再解析時はVIDEOモードの時刻要件に合わせてLandmarkerを作り直します。

## ファイル

- `index.html` — 画面。
- `app.js` — MediaPipe呼び出し、動画・canvas制御、表示、CSV出力。
- `analysis-core.mjs` — 追跡、特徴量、メタデータ検証、CSV列数検証、試行集約。
- `trial-store.mjs` — IndexedDBへの試行保存、一覧、取得、削除、JSON復元の検証。
- `test-analysis-core.mjs` — 合成データ・保存層とソース構造を確認する自動テスト。

## CSVと撮影条件

既存列を先頭に保ち、撮影条件列を末尾に追加します。座標CSVと特徴量CSVはフレーム単位、試行集約CSVは1行です。各CSVに参加者ID、試行ID、元動画ファイル名を含めます。撮影条件は `camera_angle`, `camera_height_cm`, `camera_to_hand_distance_cm`, `writing_surface`, `pen_type`, `task_type`, `capture_notes` です。空欄の条件は空セルになります。出力時にヘッダーとデータ行の列数が一致しない場合、CSV生成を止めて画面にエラーを表示します。

参加者IDには匿名IDを使用してください。元動画名に氏名等が入っている場合はCSVにも記録されるため、研究用に匿名化したファイル名に変更してください。

## 特徴量と研究上の注意

手首・指先の画像速度は、正規化画像座標x/y/zのユークリッド距離を実際の動画時刻差（秒）で割り、**正規化座標単位/秒**として記録します。m/sではなく、ペン先や実際の筆記速度を測った値でもありません。未検出、ID不明、時間差0以下、0.4秒より長い間隔をまたぐ場合は欠損値にします。

別のworld座標速度は、MediaPipeが出力する手の幾何学的中心を原点とした3D座標（メートル）から計算します。画像座標とは混合しません。これも手のランドマーク推定値であり、ペン先の動きを直接測った速度ではありません。

特徴量には指関節角度、手首からの指先相対位置、連続観測間の指先移動距離・速度、手首・指先速度、移動方向の変化を含みます。角度のゼロ除算やNaN座標は欠損として扱います。集約値は有効観測数3以上の場合のみ平均・標本標準偏差を出し、それ未満なら統計値を空欄にして件数は残します。試行の検出率は「1本以上の手が検出されたフレーム数 / 全解析フレーム数」、欠損率はその補数です。

解析前に筆記に使う手（右/左）を選択できます。鏡像動画の場合は補正を有効にしてください。MediaPipeの左右ラベル、鏡像補正後の解析側、アプリ独自の推定追跡IDは別々に記録します。左右判定の信頼度が低い場合や、筆記側の候補が複数ある場合はそのフレームを不明/曖昧とし、筆記側特徴量の集約から除外します。Hand Landmarkerは被写体基準のhandednessを返し、鏡像入力ではラベルの解釈に注意が必要です。

トラッキングはhandedness（左右推定）、手首位置、移動ゲートで行うアプリ独自推定です。追跡IDはMediaPipe公式IDでも人物IDでもありません。競合候補は「追跡不明」とし、未検出フレームで状態をリセットします。追跡IDが切り替わる回数はフレームCSVの `tracking_status=new` と `tracking_status=unknown`、`estimated_track_id` を確認してください。手の交差・遮蔽・急な移動時は誤対応し得ます。

角度変化は連続して対応づけられた同一追跡IDの関節角度差（度）です。指先間距離は正規化画像座標の3D距離（正規化座標単位）です。速度・角度・距離はいずれも筆記速度や文字の正確性を直接測るものではありません。検出率と筆記側検出率、欠損連続区間、追跡ID切替えを撮影条件と併せて確認してください。

## 試行の保存と再利用

参加者IDと試行IDを入力して解析し、「この試行を保存」を押すと、結果とメタデータをブラウザのIndexedDBに保存できます。同じ参加者ID・試行IDは同一試行キーとなり、再保存時には上書き確認を行います。一覧では参加者IDで絞り込み、結果表示、試行集約CSVの出力、削除ができます。全試行集約CSV、JSONバックアップの書き出し・読み込みにも対応します。JSONを読み込む際、保存済みと同じキーがあれば上書き確認をします。動画本体は保存対象に含みません。

## テスト

Node.js 18以降で、アプリのフォルダー内から `node --test test-analysis-core.mjs` を実行します。テストは速度の時間差、欠損リセット、両手の一対一対応、不均一/過長間隔、短い試行、欠損座標、再解析、参加者・試行集約、撮影条件の固定と未入力/不正値、CSV列数検証、筆記側選択・曖昧判定、特徴量、保存ストアの複数参加者の保存/取得/絞り込み/削除を扱います。アプリの解析開始時スナップショット・エラー時リセット・全CSVへの撮影条件連携・MediaPipeのバージョン付きES module/WASM URLと動画選択イベント登録順も確認します。

実動画を使ったブラウザ統合確認（MediaPipe/WASM読込み、動画シーク、canvas描画、実際のダウンロード）と、実際の解析失敗時のUI操作はこの環境では未検証です。エラー時の破棄動作は自動テストでコード構造も確認しますが、ブラウザ上の実挙動を保証しません。

## エラー対応

- モデル読込みに失敗する場合はCDN接続を確認します。
- 動画を開けない場合はブラウザ対応形式（例: MP4/H.264）へ変換します。
- 長い動画で遅い場合は5〜10 fpsの解析間隔を使います。`detectForVideo()` は同期実行です。
- 鉛筆による遮蔽、指の重なり、画角外、照明不足、ブレは検出・追跡の欠損につながります。検出率、欠損率、追跡IDの切替え、描画を確認し、撮影条件とともに解釈してください。
- 実測研究データがない段階で予測精度やAIの有効性を主張しません。参加者同意、匿名化、学校の研究倫理・データ管理ルールに従ってください。

## 公式仕様

[Google AI Edge Hand Landmarker Webガイド](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)に沿ってVIDEOモードの `detectForVideo()` と21点出力を使用します。同ガイドはworldLandmarksを手の幾何学的中心が原点のメートル座標と説明しています。
